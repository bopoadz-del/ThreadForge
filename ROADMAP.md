# ThreadForge Roadmap

## MVP (done)
- Pydantic digital-thread models (tags → WPs → maturity)
- DEXPI-lite + richer Proteus-shaped ingest (multi-sheet, instruments, BL)
- Topology graph + cascade dirty engine
- Test packs, AWP-shaped work packages
- 4D schedule co-activity + look-ahead (+ discipline filters, CSV/report export)
- Maturity gates (refuse IFC export early)
- Agent tool surface + SYSTEM.md + JSONL REPL + CLI + demo + tests
- Best-effort PCF text, iso JSON+SVG, GA plot SVG, shared A* routes

## Next (beyond walls)
- [ ] Optional SVG overlay bounds sync with XML tags
- [ ] Persistent store (SQLite/Postgres) for jobs & artefact registry
- [ ] IWP breakdown from CWP + craft codes
- [ ] Resource histogram (man-hours) aggregation API
- [ ] MCP / OpenAPI tool server wrapping `agent_tools`
- [ ] Multi-sheet join QA report (unmatched, ambiguous, battery limits)
- [ ] Licensed DEXPI XSD validation (when schema access available)
- [ ] Licensed PCF/ISOGEN certification pass

## Non-goals (near term)
- Full 3D CAD kernel or web viewer
- Cloning any commercial product UI or trademarks
- Real client P&ID data in fixtures
- Autodesk/AVEVA/HEXAGON API clients without entitlements
